Bienvenue ! 🎲 Voici un compagnon pour vos aventures sur Discord : un bot polyvalent, conçu pour rendre vos sessions de jeu de rôle plus fluides et agréables.

Cette page présente la syntaxe de base du bot, celle que vous utiliserez à chaque partie, puis vous indique où trouver le reste de la documentation.

## Lancer un dé

Dicelette lit directement vos messages : il n'est pas nécessaire de passer par une commande pour lancer un dé. Trois notations existent, selon ce que vous souhaitez faire de votre message.

| Notation         | Exemple                    | Résultat                                                                                                                                                      |
|------------------|----------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Directe**      | `1d20`                     | Votre message est supprimé et remplacé par le résultat, envoyé dans le salon et dans le log.                                                                  |
| **Indirecte**    | `Je force la porte [1d20]` | Votre message est conservé. Seul le contenu des crochets est lancé : le bot répond avec le résultat, et le log contient un lien vers votre message d'origine. |
| **Semi-directe** | `1d20 Je force la porte`   | Le premier dé trouvé est lancé, et le reste du message est envoyé dans le log comme [commentaire](#commentaires).                                             |

Vous pouvez aussi utiliser la commande slash `/roll` (ex. `/roll 1d20+3`). Dans tous les cas, les résultats sont centralisés dans un fil de discussion préfixé par `🎲`, le *log* : voir le [comportement par défaut](./behavior.md).

Pour le détail des trois notations, consultez [Envoi de message](../usage/message.md) et les [commandes de base](../usage/index.md#lancer-de-dés).

## Commentaires

Un commentaire ajoute du contexte à un jet : il est affiché avec le résultat. Selon ce que vous voulez annoter, il existe plusieurs façons d'en écrire un.

- **Commentaire global : `#commentaire`**. Placé à la fin du dé, il annote tout le jet. Dans un message direct, le `#` peut être omis : c'est ce qui permet la notation semi-directe.

  :::example
  - `/roll 1d20+5 #Attaque`
  - `1d20 Je force la porte`
  :::

- **Commentaire d'une ligne : `[commentaire]`**. Dans un [jet partagé](./expression.mdx#jets-uniques-partagés-réutilisation-de-résultats) (`;&`), il annote une formule précise.

  :::example[ `1d20;&-2 [perte pv] #commentaire` ]
  :::

- **Modifier un commentaire après coup : `///`**. Répondez au message du résultat avec `/// Mon commentaire`. Seuls vos propres commentaires peuvent être modifiés, sur tous les résultats lancés par le bot (commande slash ou message). `///` est le préfixe par défaut : [il est possible de le modifier](../config/user%20settings/comment_prefix.md).

Avec l'exemple de jet partagé ci-dessus, le résultat affiche le commentaire global en tête, et le commentaire de ligne souligné devant la formule concernée :

:::roll[ `1d20;&-2 [perte pv] #commentaire` ]
*commentaire*  
  ※ `1d20` ⟶ `[2]` = ` 2 `  
  ◈ <u>perte pv</u> — `[1d20]-2` ⟶ `[2]-2` = ` 0 `  
:::

:::warning Les commentaires sont sensibles aux espaces
- Un commentaire `[entre crochets]` ou `#global` doit être précédé d'un espace.
- Le `#` d'un commentaire global doit être collé à son texte : `#Attaque`.
- Dans un jet partagé, n'ajoutez pas d'espace avant ou après le `;` qui sépare les formules, sinon la suite sera considérée comme un commentaire.
:::

:::tip Les crochets `[]` ont plusieurs sens
- Dans un message, `[1d20]` désigne un dé à lancer ([notation indirecte](#lancer-un-dé)).
- Après un jet partagé, `[texte]` est un commentaire.
- Dans les dés d'un modèle, les macros et les snippets, `[valeur]` est un nombre traité comme une statistique : voir la page [Syntaxe](./format.mdx).
:::

## Statistiques et personnages

Si vous avez enregistré une fiche de personnage (ou des attributs), vous pouvez utiliser vos statistiques directement dans un jet :

- **`$statistique`** : valeur d'une statistique, par exemple `1d20 + $force`. Pour l'utiliser comme nombre de dés, écrivez `($force)d20`.
- **`@personnage`** : lance le dé avec un personnage précis, par exemple `1d100 @Bob`.

Les modérateurs peuvent aussi mentionner un joueur dans un message direct pour lancer un dé à sa place.

Pour créer votre premier personnage, voir [Fiche de personnage](../sheet/model/index.md) et [Enregistrer un utilisateur](../sheet/user.md).

## Réussites et échecs

Quand un dé est suivi d'un signe de comparaison (`>`, `<`, `=`…), le bot compare le résultat et indique s'il s'agit d'un succès ou d'un échec. Avec `1d20>10` :

:::roll[ **Succès** — `1d20` ⟶ `[20]` = `[20] > 10` ]
:::

- Pour ajouter une **opposition**, superposez les signes : `1d100>20>10` (le dernier est l'opposition).
- Pour **compter** les dés qui passent une comparaison plutôt que de comparer le total, placez-les entre accolades : `{3d12>20}`.

Le détail de ces règles se trouve dans la page [Notations des dés](./expression.mdx#les-comparateurs).

## Lire la syntaxe des commandes

Dans la documentation, les champs des commandes sont décrits ainsi :

- <mark class='green'>`[champ]`</mark> : obligatoire.
- <mark class='green'>`(champ)`</mark> : facultatif.
- <mark class='green'>`(*champ)`</mark> : auto-complété.
- <mark class='green'>`@champ`</mark> : une mention (utilisateur ou rôle, selon la commande).
- <mark class='green'>`#champ`</mark> : un salon.
- <mark class='green'>`?champ`</mark> : une valeur vrai/faux.

Par exemple, `/roll (dice) (?caché)` désigne une commande dont les deux champs sont facultatifs, le second étant un vrai/faux. Voir la page [Syntaxe](./format.mdx#syntaxe-des-commandes) pour l'auto-complétion des personnages.

## Fonctionnalités principales

### 🎲 Système de dés avancé

- **Lancers de dés flexibles** : Support complet des [expressions complexes](./expression.mdx) pour supporter tous les types de jets.
- **Dés personnalisés** : Créez et utilisez des dés spécifiques à vos personnages et campagnes.
- **Gestion automatique des résultats** : Les résultats peuvent être organisés dans des [fils de discussion dédiés](../config/threads.md) pour éviter l'encombrement, ou renvoyer dans un salon spécifique.

### 📊 Gestion complète des personnages

- **Modèles de serveur** : Configurez un [modèle unique](../sheet/model/index.md) adapté à votre système.
- **Fiches de personnage** : [Enregistrement simple](../sheet/user.md) avec une interface intuitive.
- **Statistiques dynamiques** : Modifiez et mettez à jour vos personnages.
- **Multi-personnages** : Gérez plusieurs personnages par utilisateur.
- **Fiches privées** : Contrôlez la visibilité des informations des personnages.

### 🔧 Configuration flexible du serveur

- **Paramètres personnalisables** : Adaptez le bot à vos besoins avec de nombreuses [options de configuration](../config/index.md).
- **[Auto-rôles](../config/auto_role.md)** : Attribution automatique de rôles pour une gestion simplifiée des permissions.
- **[Journalisation](../config/logs.md)** : Suivi des modifications et gestion des erreurs
- **[Auto-enregistrement](../config/self_registration.md)** : Permettez aux joueurs d'enregistrer leurs propres personnages
- **[Suppression des messages HRP](../config/strip_ooc.md)** : Nettoyage automatique des messages hors roleplay
- **[Options d'affichage](../config/display.md)** : Personnalisez l'affichage des résultats (timestamps, délais de suppression, lien d'ancrage...)
- **Support multilingue** : Interface disponible en français et anglais

### 🎭 Fonctionnalités pour maîtres de jeu[^1]

- **Jets pour les joueurs** : Effectuez des jets au nom de vos joueurs.
- **Jet invisible** : Faites des jets cachés aux joueurs pour maintenir le suspense.

### 🛠️ Outils pratiques

- **Import/Export** : [Sauvegardez et transférez](../sheet/import_export.md) vos données facilement
- **Système d'aide intégré** : Accès rapide à la documentation et aux guides
- **Nettoyage automatique** : Gestion intelligente des données obsolètes
- **Interface utilisateur intuitive** : Formulaires et menus interactifs pour simplifier l'utilisation

## Vos données

Dicelette ne conserve que l'essentiel (identifiants de messages, liens entre joueurs et personnages, paramètres du serveur et modèles) : vos fiches de personnage restent dans vos messages Discord. Pour le détail du stockage, du nettoyage automatique et pour demander la suppression de vos données, voir [Fonctionnement technique](../dev/technique.md).
